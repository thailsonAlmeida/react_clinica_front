# Bibliotecas
- Axios
```bat
yarn add axios@0.27.2
```

- QS
```bat
yarn add qs@6.11.0 @types/qs@6.9.7
```

- History
```bat
yarn add history@5.3.0
```

- jwt-decode
```bat
yarn add jwt-decode@3.1.2 @types/jwt-decode@3.1.0
```
